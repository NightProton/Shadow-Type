# 🌑 Shadow Type

> A fast-paced typing game where players must reverse and type words correctly under time pressure — while dealing with random distractions, glitches, and audio interruptions.

---

## 🎮 Features

- **Reverse typing mechanic** — type every word backwards
- **Increasing difficulty** based on word length and score
- **5-minute timer** — race the clock
- **Random distraction popups** to simulate loss of focus
- **Glitch effects** that randomly alter your input
- **Dynamic sound effects** and meme audio interruptions
- **Neon-themed animated UI**
- **Encrypted performance stats** downloaded at the end

---

## 🕹️ Gameplay

1. Click anywhere on the screen to start
2. A word will be displayed on screen
3. Type the **reversed** version of the word
4. Press **Enter** to submit
5. Correct answers increase your score; wrong answers decrease it
6. Keep going until the timer runs out!

---

## ⌨️ Controls

| Action | Control |
|--------|---------|
| Type answer | Keyboard |
| Submit answer | `Enter` |

---

## 📊 Scoring

| Result | Points |
|--------|--------|
| Correct reverse | `+1` |
| Incorrect attempt | `-1` |
